No processo de ETL com Python, utilizando a biblioteca pandas, os dados foram organizados em duas etapas:

- RAW - Dados Brutos
Nesta fase, os dados estão em sua forma original, sem qualquer tipo de processamento ou refinamento.

- Ready - Dados Prontos
Após passar pelo processo de refinamento, os dados foram transformados e organizados.

Durante esse refinamento, uma nova planilha do Excel foi gerada com os dados tratados. Entre as melhorias aplicadas, destaca-se a mesclagem automática de todas as bases,
a criação da coluna location para garantir rastreabilidade consistente, e a extração automática da informação da campanha de um link para compor a coluna campaign.
Além disso, foram realizados diversos processos de limpeza e padronização dos dados, preparando-os para análises futuras.
